# TOPIX-17 業種モメンタム・バックテストシステム仕様書

## 1. 概要

### 1.1 目的

TOPIX-17に連動するETFの過去価格データを利用し、日経平均より相対的に強い業種へ投資する「業種モメンタム戦略」の有効性をバックテストする。

本システムでは、一定期間ごとの騰落率から業種ごとの相対強度を計算し、ランキング上位3業種を均等保有する。

毎月ランキングを再計算し、上位業種が入れ替わった場合はポートフォリオをリバランスする。

将来的には、上位業種を選択した後、その業種に属する個別株からさらに強い銘柄を選択する機能を追加する。

---

# 6. 使用価格

## 6.1 シグナル計算

モメンタム計算では、配当・分割等を考慮した調整済み価格を利用する。

基本的には、

```text
Adj Close
```

相当の値を使用する。

ただしyfinanceの`auto_adjust`の仕様を確認し、二重調整にならないようにすること。

---

## 6.2 売買価格

実際の売買価格については、

```text
Open
```

を使用する。

つまり、

```text
月末営業日の終値までの情報でランキング決定
↓
翌営業日の始値で売買
```

とする。

これにより、月末終値を確認した時点では知ることのできない価格で売買するルックアヘッドバイアスを防ぐ。

# 7. モメンタム計算

## 7.1 基本期間

以下の3期間を使用する。

```text
3か月
6か月
12か月
```

ただし将来変更できるよう設定化する。

---

## 7.2 初期設定

```python
momentum_periods = {
    3: 0.50,
    6: 0.30,
    12: 0.20,
}
```

---

## 7.3 リターン計算

各月末時点で以下を計算する。

例：

```text
3か月リターン
=
現在価格 / 約3か月前価格 - 1
```

ただし「3か月＝63営業日」のような固定営業日数ではなく、原則として月単位の過去月末価格を利用する。

例：

2026年8月31日の判定の場合、

```text
3か月
2026年5月末 → 2026年8月末

6か月
2026年2月末 → 2026年8月末

12か月
2025年8月末 → 2026年8月末
```

対象月末が休日の場合は、その月の最終取引日の価格を使用する。

# 8. 相対リターン

各業種ETFについて、日経平均との差を計算する。

### 3か月相対リターン

```text
ETF 3か月リターン
-
日経平均 3か月リターン
```

### 6か月相対リターン

```text
ETF 6か月リターン
-
日経平均 6か月リターン
```

### 12か月相対リターン

```text
ETF 12か月リターン
-
日経平均 12か月リターン
```

---

# 9. 業種モメンタムスコア

以下の式をデフォルトとする。

```text
Momentum Score
=
3か月相対リターン × 0.50
+
6か月相対リターン × 0.30
+
12か月相対リターン × 0.20
```

例：

```text
3か月相対リターン = +10%
6か月相対リターン = +8%
12か月相対リターン = +4%

Score
= 0.10 × 0.50
+ 0.08 × 0.30
+ 0.04 × 0.20

= 0.082
= 8.2%
```

# 10. ランキング

毎月最終営業日の終値確定後に、17業種のMomentum Scoreを計算する。

Scoreの高い順に、

```text
1位
2位
3位
...
17位
```

とランキングする。

デフォルトでは、

```text
上位3業種
```

を翌月の投資対象とする。

均等配分とする。

## 11.4 売買単位

バックテストでは実際のETFの売買単位は考慮しない。

小数株の保有を許可し、理論上完全な均等配分が可能なものとする。

例：

```text
投資資金500,000円
↓
166,666.67円 × 3業種
```

---

## 11.5 現金比率

原則として100%投資する。

```text
現金待機用の固定割合なし
```

売買処理により生じる微小な端数は無視してよい。

# 12. リバランス

## 12.1 タイミング

月1回。

```text
毎月最終営業日
    ↓
終値確定
    ↓
ランキング計算
    ↓
翌営業日の始値で売買
```

---

## 12.2 例

4月最終営業日：

```text
ランキング

1位 銀行
2位 機械
3位 商社
```

翌営業日：

```text
銀行 33.3%
機械 33.3%
商社 33.3%
```

5月最終営業日：

```text
1位 銀行
2位 電機
3位 商社
```

翌営業日：

```text
機械を売却
電機を購入
```

---

## 12.3 リバランス方法

ランキング上位3銘柄すべてについて、毎月均等配分になるようリバランスする。

つまり、同じ3銘柄が継続してランキング入りしている場合でも、

```text
33.33%
33.33%
33.33%
```

へ戻す。

これにより、銘柄ごとの値動きによる配分偏りを毎月リセットする。

# 15. バックテスト開始可能日

12か月モメンタムを利用するため、十分な過去データが存在しない期間は売買を行わない。

例：

```text
データ取得開始
2008年3月

↓

12か月分のデータ蓄積

↓

2009年3月以降からシグナル生成可能
```

さらに翌営業日の始値で売買するため、その価格が存在する必要がある。

---

# 16. 欠損データ

以下の場合は無理に補完しない。

- ETFに対象日の価格がない
- 上場前
- データ欠損
- 日経平均データ欠損

前営業日・翌営業日の価格で機械的に穴埋めすることは原則行わない。

月末価格については、その月の最後に実際に存在する取引日の価格を使用する。

あるETFについて必要な12か月分のデータが取得できない場合、その月のランキング対象から除外する。

ただしバックテスト初期に一部ETFだけデータ不足となることで投資可能業種数が変わる場合は、ログ等で確認できるようにする。

---

# 17. サバイバーシップ等について

Phase 1では現在存在するTOPIX-17連動ETFを使って過去検証する。

そのため、厳密な意味で実際のTOPIX-17指数そのものを使用した検証とは異なる。

また、

- ETFの信託報酬
- ETFの需給
- トラッキングエラー
- 出来高
- 指数とETF価格との差

等の影響が含まれる可能性がある。

今回は「業種モメンタム戦略そのものに優位性がありそうか」を確認することを主目的とする。

## 18.3 CAGR

年平均成長率。

```text

=
(最終資産 / 初期資金)^(1 / 経過年数) - 1
```

---

## 18.4 最大ドローダウン

ピーク時点から、その後の最安値までの最大下落率。

```text

```

---

## 18.5 年率ボラティリティ

日次リターンの標準偏差から算出。

```text
daily_return.std() × sqrt(252)
```

---

## 18.6 シャープレシオ

Phase 1では無リスク金利を0%とする。

```text
Sharpe Ratio
=
年率リターン / 年率ボラティリティ
```

より正確な日次計算を採用してもよい。

# 27. 日付処理

ETFと日経平均で取引日が異なる場合があるため、

```text
単純な配列index依存
```

は避ける。

DatetimeIndexを使用し、実際の日付を基準に処理する。

売買日は、

```text
シグナル日より後で
必要な対象銘柄すべてについて価格取得可能な
最初の取引日
```

を原則とする。

ただし特定ETFのみ価格が欠損している場合にバックテスト全体を不自然に遅らせないよう、実装時にはログを出し、挙動を確認できるようにする。

# 28. 初回投資

最初に12か月分のモメンタムデータが揃った月末でランキングを作成する。

その翌営業日に初回投資する。

それ以前は、

```text
Cash = 100%
```

とする。

ただしパフォーマンス比較期間については、

```text
初回投資日
```

を実質的なバックテスト開始日として扱う。

ベンチマークの日経平均も同じ日からスタートさせる。

# 29. テスト

最低限、以下についてユニットテストを書く。

## 29.1 モメンタム

既知の価格データから、

```text
3M
6M
12M
```

リターンが正しく計算されること。

---

## 29.2 相対リターン

例：

```text
ETF = +15%
Nikkei = +10%

Relative Return = +5%
```

となること。

---

## 29.3 Momentum Score

例：

```text
3M = 10%
6M = 8%
12M = 4%

Score = 8.2%
```

になること。

---

## 29.4 ランキング

Score順に正しく並ぶこと。

---

## 29.5 TOP3

17銘柄から上位3銘柄のみ選択されること。

---

## 29.6 均等配分

300,000円の場合、

```text
100,000円
100,000円
100,000円
```

へ配分されること。

---

## 29.7 ルックアヘッド

シグナル日当日のOpenやCloseを売買価格として使用せず、

```text
翌営業日のOpen
```

が利用されること。

---

## 29.8 リバランス

前月：

```text
A
B
C
```

翌月：

```text
A
B
D
```

の場合、

```text
C SELL
D BUY
```

が発生すること。

さらにA・B・Dが均等配分になること。

# 35. 最重要事項

本システムの目的は、

```text
最も利益の大きかったパラメータを探すこと
```

ではなく、

```text
業種モメンタムという考え方に
期間をまたいで再現可能な優位性が存在するか確認すること
```

である。

そのためバックテスト結果を評価する際には、CAGRだけで判断せず、

```text
日経平均をどの程度上回ったか
最大ドローダウン
シャープレシオ
年ごとの安定性
特定期間だけに依存していないか
```

を重視する。

また、バックテスト結果を見た後で都合よくパラメータを変更し続けることによる過学習に注意する。
